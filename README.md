# organizador-archivos
Script de Python que organiza automáticamente archivos de Descargas en carpetas por categorí.
## ¿Cómo funciona?
El script lee los archivos de la carpeta Descargas y los mueve
automáticamente a carpetas organizadas por categoría: Imágenes,
Audio, Videos, Documentos, Archivos y Otros.

## Librerías usadas
- os
- shutil
- pathlib

## ¿Cómo usarlo?
1. Clona el repositorio
2. Ejecuta el archivo main.py
